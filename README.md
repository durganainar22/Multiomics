# Multi-Omics BRCA Cancer Subtype Prediction

A machine learning pipeline integrating RNA-seq, DNA methylation, and somatic mutation data from TCGA to classify breast cancer molecular subtypes using XGBoost with 81.6% test accuracy.

---

## Biological Question

Breast cancer is not a single disease — it has four distinct molecular subtypes (Luminal A, Luminal B, HER2-enriched, and Basal-like) with different prognoses and treatment responses. Can we accurately predict a patient's subtype by integrating multiple layers of genomic data?

---

## Results

| Model | CV Accuracy | Test Accuracy |
|---|---|---|
| Logistic Regression | 75.5% ± 4.6% | 75.5% |
| Random Forest | 73.7% ± 2.6% | 77.6% |
| **XGBoost** | **77.6% ± 2.3%** | **81.6%** |

| Subtype | Precision | Recall | F1 | AUC |
|---|---|---|---|---|
| Basal | 0.88 | 0.94 | 0.91 | 1.00 |
| Her2 | 0.83 | 1.00 | 0.91 | 1.00 |
| LumA | 0.82 | 0.88 | 0.85 | 0.93 |
| LumB | 0.72 | 0.57 | 0.63 | 0.89 |
| Normal | 1.00 | 0.67 | 0.80 | 0.95 |

### Key Findings
- RNA-seq PC1 and PC2 are the strongest predictors — gene expression dominates subtype classification
- ER receptor status is the 3rd most important feature — validates known clinical biology
- Methylation PCs contribute complementary signal beyond expression alone
- Basal-like tumors are perfectly separable (AUC = 1.00) — consistent with their distinct molecular profile

## Pipeline Overview

```
TCGA-BRCA Data (GDC API)
        │
        ├── RNA-seq (1,231 samples)
        ├── Methylation 450k (895 samples)  
        ├── Mutation MAF (992 samples)
        └── Clinical / PAM50 labels
        │
        ▼
Section 2: EDA
    - Distribution plots, variance analysis, library size QC
        │
        ▼
Section 3: Preprocessing
    - Filter top 5,000 variable genes/probes
    - Log2 normalize + StandardScaler (RNA-seq)
    - Impute missing values (methylation)
    - Filter to 18 recurrently mutated genes
    - Align to 486 common patients with PAM50 labels
        │
        ▼
Section 4: Feature Engineering
    - Mutation burden per patient
    - ER/PR/HER2 receptor status encoding (subtype-aware imputation)
        │
        ▼
Section 5: Dimensionality Reduction
    - PCA: RNA-seq → 50 PCs (62.6% variance)
    - PCA: Methylation → 50 PCs (varies)
    - PCA: Mutation → 10 PCs (77.6% variance)
        │
        ▼
Section 6: Multi-Omics Integration
    - Concatenate all PCA results + clinical features
    - Final matrix: 486 patients × 114 features
        │
        ▼
Section 7: Model Training
    - Stratified 5-fold cross-validation
    - Compare LR, RF, XGBoost
    - Final evaluation on held-out test set
        │
        ▼
Section 8: Interpretation
    - SHAP feature importance
    - ROC curves per subtype
```

## Dataset

- **Source**: The Cancer Genome Atlas (TCGA-BRCA) via GDC Data Portal
- **PAM50 labels**: UCSC Xena clinical matrix
- **Final cohort**: 486 patients with all three omics layers and PAM50 labels
- **Subtypes**: LumA (252), LumB (116), Basal (77), Her2 (27), Normal (14)

## Reproducing the Analysis

## Requirements

```bash
conda create -n multiomics python=3.11
conda activate multiomics
pip install pandas numpy scipy scikit-learn matplotlib seaborn xgboost shap jupyter ipykernel requests pyarrow seaborn
```

Full package list:
- `pandas` — data manipulation
- `numpy` — numerical computing
- `scipy` — scientific computing
- `scikit-learn` — machine learning, preprocessing, evaluation
- `matplotlib` / `seaborn` — visualization
- `xgboost` — gradient boosting classifier
- `shap` — model interpretation
- `jupyter` / `ipykernel` — notebook environment
- `requests` — GDC API calls
- `pyarrow` — parquet file format support

### Data Download

Download TCGA-BRCA data using [GDC Data Transfer Tool](https://gdc.cancer.gov/access-data/gdc-data-transfer-tool) with the manifests generated in Section 1 of the notebook.

### Run

```bash
jupyter notebook project.ipynb
```

Run all cells in order. Sections 1-2 require downloading raw data (~15GB). Sections 3-8 can be run from saved parquet files.
